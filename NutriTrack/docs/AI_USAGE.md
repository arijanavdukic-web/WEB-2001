# AI Usage Documentation – NutriTrack

## 1. Introduction

Artificial Intelligence tools were used during the development of NutriTrack as supporting tools for selected development tasks. AI assistance was used to improve development efficiency, generate initial code structures, prepare testing data, assist with styling, and help identify and resolve programming errors.

The student remained responsible for project development, integration, testing, and understanding of the implemented functionality.

## 2. Areas of AI Assistance

### 2.1 Frontend Development

AI assistance was used for:
- Bootstrap component suggestions and implementation.
- CSS styling and layout improvements.
- Suggestions for responsive design.
- Repetitive HTML, CSS, and JavaScript boilerplate.

### 2.2 Database Development

AI assistance was used to:
- Generate sample (dummy) data for database testing.
- Suggest example SQL INSERT statements.
- Help organize test records for the database entities.

The database structure and relationships were reviewed and implemented as part of the project development.

### 2.3 Backend Development

AI assistance was used as a supporting tool for:
- Explaining standard PHP class structures.
- Providing initial examples of DAO classes.
- Explaining CRUD operations.
- Demonstrating the use of PDO and prepared statements.
- Suggesting reusable code structures.

The student integrated the code into the project and tested the database connection and DAO functionality.

### 2.4 Debugging and Testing

AI assistance was used to:
- Interpret PHP warnings and error messages.
- Suggest possible solutions to configuration issues.
- Explain test results.
- Help prepare temporary testing scripts.

The student executed the tests locally and verified the results.

## 3. Examples of AI Prompts

The following are representative examples of prompts used during development. They are summaries of the requests made during the development process, not necessarily verbatim transcripts.

- "Help me create Bootstrap components and improve the CSS styling of my web application."
- "Generate sample SQL data for my database tables."
- "Explain how to create a reusable BaseDAO class in PHP using PDO."
- "Help me implement CRUD operations using prepared statements."
- "Explain this PHP database connection error and help me fix it."
- "Help me test whether my DAO classes can retrieve records from MySQL."

## 4. Student Responsibilities

The student was responsible for:
- Organizing the project structure.
- Creating and configuring the MySQL database.
- Integrating the frontend and backend components.
- Running the application in the local development environment.
- Testing database connections and CRUD operations.
- Reviewing and adapting AI-generated suggestions.
- Understanding the purpose and functionality of the implemented code.

AI-generated suggestions were treated as assistance and were reviewed before being integrated into the project.

## 5. Conclusion

AI tools were used as development support rather than as a replacement for the student's work. Their purpose was to assist with repetitive implementation tasks, provide explanations, generate test data, and support debugging.

The student remains responsible for the final implementation and is expected to understand and explain the project's architecture and functionality.
